# oneform: как оформлять обычную форму и проверять раскладку

Числа ниже измерены на 2 945 формах УТ 10.3 и Бух. (`docs/form-design-standards.md`; машинная версия — `docs/design/design-rules.json`).
`pack` ничего не пересчитывает: поменял размер формы — сам поправь панели и привязки. Проверка — `oneform lint`.

## Когда применять

* Новая форма (`new-form`, `clone-form`) или новые поля/таблицы в существующей: расставь по рецепту своего вида и прогони `lint`.
* Форма «поехала» после смены `Width`/`Height`: `lint` покажет, что не пересчитано (нижняя панель, поле у правого края).
* Не нужен: правка свойств без геометрии (заголовок, шрифт, обработчик).

## Система координат

* Всё в пикселях; `Left`/`Top` элемента отсчитываются от левого верхнего угла формы, у элементов страницы панели — от страницы.
* Страница панели размера `W×H` занимает `Left 1, Top 19, Width W−2, Height H−20` (в координатах панели; её геометрию не пишите, она выводится из размера панели); внутри страницы поля по 6 px.
* Панели команд: верхняя `ДействияФормы` — `Left 0, Top 0, Width = ширина формы, Height 25`; нижняя `ОсновныеДействияФормы` — `Left 0, Top = Height формы − 25, Width = ширина формы, Height 25`.

## Рецепты по видам формы

Общее для всех: левое и правое поле **8**; первый элемент под верхней панелью на `Top 33` (25 + 8); последний элемент заканчивается на 8 px выше нижней панели
(`Top нижней панели − 8`); высота поля, надписи, флажка **19**; надпись и её поле на одном `Top`; надпись слева, заканчивается «:», имя `Надпись<Поле>`.

| Вид | Размер Ш×В | Панели | Содержимое |
|---|---|---|---|
| Элемент справочника | 500 (400–600) × по содержимому | верхняя + нижняя `OK` `Записать` `Закрыть` (латинские `OK`) | пары надпись–поле, поля растягиваются вправо |
| Группа справочника | 400 × ~110 | как у элемента | `Наименование`, `Код` |
| Список / выбор справочника | 400 × 300 | только верхняя (выбор: `Выбрать`/`Закрыть`) | одна таблица: `Left 8, Top 33`, до правого поля и до низа (зазор 8), растягивается по обеим осям |
| Документ | 700 × 465 (медиана 436) | верхняя + нижняя `OK` `Провести` `Записать` `Закрыть` | шапка полями, ниже панель с закладками `Left 8`, таблицы на страницах |
| Список / выбор документа | 742 (780) × 300 (421) | только верхняя | одна таблица на всю ширину |
| Обработка | 700 × 400 | нижняя (`Выполнить` `Закрыть`) в 54 % форм | как у документа/элемента |
| Отчёт | 780 × 450 | нижняя `ОК` `Закрыть` в 21 % форм | настройки сверху, результат ниже |

Ширина поля по типу: `Date` 80; `DateTime` 120; число — 60 (Бух.) или 80 (УТ); ссылка 220–250; строка до 25 знаков 80–110, до 50 — 220–315, длиннее — 315, неограниченная — 569.
Шаг строк: элемент справочника 23 (Бух.) / 24 (УТ); документ 24 (УТ) / 23 (Бух.); обработка 24; отчёт 23.
Таблица над собой имеет командную панель `Height 24`, вплотную (`Top таблицы − 24`), той же ширины.

### Привязки

* Поле, дошедшее до правого поля (`Left + Width = ширина − 8`), растягивается: `<Anchors right="Right" rightOffset="-8"/>`; надпись не растягивается (`Anchors` не писать).
* Таблица: `right="Right" rightOffset="-8" bottom="Bottom" bottomOffset="-<зазор до низа>"` (зазор до нижней панели или края — 8, на странице — 6).
* Нижняя панель: `top="Bottom" topTarget="<её id>" topOffset="-25" bottom="Bottom" left="Left" right="Right"`; верхняя: `bottom="Top" bottomTarget="<её id>" bottomOffset="25" left="Left" right="Right"`.
* Изменил `Width`/`Height` формы — пересчитай `Width`/`Top` панелей, `rightOffset`/`bottomOffset` растягивающихся элементов.

### Порядок обхода

`TabOrder` идёт по чтению: сверху вниз, слева направо; верхняя панель 1; поле = `TabOrder` своей надписи + 1; нижняя панель последняя. Новый элемент в середине формы получает
следующий свободный номер — перенумеруй соседей. `ZOrder` и `TabOrder` считаются на странице панели отдельно.

## Пример: форма элемента справочника «Контрагенты», стиль Бух.

Форма 500×131: `ДействияФормы` `0,0,500,25`; три строки с шагом 23 — метка `Left 8, Width 150`, поле `Left 158` (зазор 0):

| Строка | Top | Надпись (Left, Width) | Поле (Left, Width) | TabOrder |
|---|---|---|---|---|
| Код | 33 | `НадписьКод` 8, 150 | `Код` 158, 100 (фикс.) | 2, 3 |
| Наименование | 56 | `НадписьНаименование` 8, 150 | `Наименование` 158, 334 (растяг.) | 4, 5 |
| Комментарий | 79 | `НадписьКомментарий` 8, 150 | `Комментарий` 158, 334 (растяг.) | 6, 7 |

Последняя строка кончается на 98; 98 + 8 = 106 = `Top` нижней панели; 106 + 25 = 131 = `Height` формы. Правый край полей `158 + 334 = 492 = 500 − 8`.
Одна строка в XML (`Height` 19, надпись и поле на одном `Top`, `ZOrder` = `id`):

```xml
<InputField name="Наименование" id="5">
  <DataPath attributeId="0">СправочникОбъект.Наименование</DataPath>
  <Left>158</Left><Top>56</Top><Width>334</Width><Height>19</Height>
  <ZOrder>5</ZOrder><TabOrder>5</TabOrder>
  <Anchors right="Right" rightOffset="-8"/>
</InputField>
```

Этот пример `oneform lint` проходит без замечаний.

## УТ или Бух.: что различается и что выбрать

| Параметр | УТ 10.3 | Бух. |
|---|---|---|
| зазор надпись → поле | 2 (элемент), 0 (документ) | 0 |
| ширина надписи | 84 (элемент), 88 (документ) | 150 (элемент), 115 (документ) |
| шаг строк | 24 | 23 |
| имя поля = имя реквизита | 51 % (элемент) | 97 % |
| `OK` в нижней панели документа | кириллица `ОК` 56 % | латиница `OK` 100 % |
| подпись «автор» в строке нижней панели документа | нет | есть (99 %) |
| подписи жирным (документ) | 1 % | 42 % |
| ширина формы документа | 652 | 700 |

Выбор: смотри **соседние формы той же конфигурации и того же вида** (`FormPreview.html` или `Form.xml` двух-трёх форм) и копируй их шаг строк, зазор и ширину надписи.
Нет образцов — бери колонку Бух.: её правила однороднее (ширина документа 700 — 92 % форм, зазор 0 — 94 %). Не смешивай два стиля в одной форме.
`lint` не навязывает расходящиеся правила: они в `info` только если вид един (≥ 85 %).

## Проверка: `oneform lint`

```bash
oneform lint <каталог>             # каждая src/Forms/*/Form.xml; ничего не пишет
oneform lint <каталог> --json      # массив замечаний: form, file, kind, severity, rule, line, control, message, fix, share
oneform lint <каталог> --strict    # код 3, если есть warning (без --strict код 0)
```

Строка: `Documents/Приказ/ФормаАгента: warning overlap line 473: НовыйНомер: overlaps 'НадписьАвтор' … (fix: …)`. `line` — строка в `Form.xml`, `fix` — что сделать.
Код выхода: 1 — есть `error`; 3 — `--strict` и есть `warning`; иначе 0. Замечания `pack` не блокируют.

| Уровень | Правила |
|---|---|
| `error` | `outside-container` (элемент за краем формы или страницы, отрицательные координаты), `duplicate-name`, `duplicate-id` — исправь |
| `warning` | `overlap` (пересечение > 2 px), `covers-bottom-bar`, `bottom-bar-position`/`-width`/`-anchor` (нижняя панель не на `Top = Height − 25`, не во всю ширину, не привязана к низу/правому краю), `top-bar-position`/`-width`, `field-no-stretch`, `table-no-stretch`, `table-no-stretch-bottom`, `label-row` (надпись выше/ниже поля больше чем на 6 px), `anchor-mismatch` (край привязан к своей стороне без цели: `top="Top" topOffset=K`, а `Top` ≠ K; так же `left`, а для `bottom="Top"` / `right="Left"` смещение равно `Top + Height` / `Left + Width`; в `fix` — верное смещение или координата; в выгрузках совпадает в 99,8 % случаев) |
| `info` | `margin-*`, `*-bar-height`, `field-height`, `label-height`, `form-width`/`form-height`: отличие от обычного значения вида формы (`share=NN %`, `kind=…`); `tab-order` — обход против чтения |

Правило из таблицы замеров считается `warning`, только если ему следуют ≥ 85 % форм вида и УТ с Бух. не расходятся; иначе то же замечание приходит как `info` с долей.
Ограничения: `lint` не знает, какие из наложенных друг на друга элементов модуль показывает по очереди (полностью вложенные пропускаются), не проверяет текст и размеры шрифта,
читает только `Form.xml`. `info` с долей < 100 % — подсказка, а не требование.

## Чек-лист

1. Вид формы определён; размер, панели и состав — по таблице видов.
2. Поля 8, первая строка `Top 33`, шаг строк 23 или 24 (один на форму), высоты 19, надпись и поле на одном `Top`.
3. Правый край растягиваемых полей на `ширина − 8`, `Anchors right="Right"`; таблицы растягиваются по обеим осям.
4. Нижняя панель `Top = Height − 25`, `Width` формы, привязана; верхняя `Top 0`.
5. `TabOrder` по чтению, у поля номер надписи + 1; нижняя панель последняя.
6. Менял размер формы — пересчитаны панели и смещения привязок.
7. `oneform lint <каталог>`: ноль `error`, `warning` исправлены или обоснованы; затем `pack --dry-run`.
