# input-field-selection-buttons — кнопки выбора у нового ссылочного поля

**Состояние: закрыто 28.10.2026.** Проверка в 1С выполнена (пункт 1.4).

## Сценарий
Тестовая база «Бух.», справочник `ДоходыБудущихПериодов`, форма `ФормаАгентаН` (элемент справочника, из `new-form`).
В `Form.xml` добавлено поле **без** флагов `ChoiceButton`/`OpenButton`/`ClearButton`:

```xml
<InputField name="ПолеТестСсылка" id="90">
  <DataPath attributeId="0">СправочникОбъект.СтавкаНДС</DataPath>
  <Left>100</Left><Top>120</Top><Width>200</Width><Height>19</Height><ZOrder>30</ZOrder><TabOrder>30</TabOrder>
</InputField>
```

`oneform pack` → частичная загрузка в базу → запуск лаунчера (`scripts/1c-e2e/live/`) → дамп свойств элементов.

## Результат (дамп [`catalog-item-after`](files/input-field-selection-buttons/catalog-item-after.txt.gz))

| Поле | Данные | КнопкаВыбора | КнопкаОткрытия | КнопкаОчистки |
|---|---|---|---|---|
| `ПолеТестСсылка` (новое, без флагов) | СтавкаНДС | Да | Да | Нет |
| `ПолеВид` (ссылка на справочник) | ВидНоменклатуры | Да | Да | Нет |
| `ПолеТип` (перечисление) | ТипНоменклатуры | Да | Нет | Нет |
| `ПолеНач` (дата) | ДатаНачалаСписания | Да | Нет | Нет |
| `ПолеКод` (строка) | Код | Нет | Нет | Нет |

## До исправления
Внешняя обработка с двумя добавленными ссылочными полями (26.10.2026, дамп [`processor-after`](files/bind-controls-to-object-attributes/processor-after.txt.gz)): у новых полей `КнопкаВыбора=Нет`, `КнопкаОткрытия=Нет`.
