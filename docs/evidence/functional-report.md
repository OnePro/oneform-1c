# functional-report — правка настоящего внешнего отчёта (панель `ПанельНастроек`)

**Дата:** 27.10.2026. **База:** «Бух.» (платформа 8.3.27.2342), пользователь `admin`. **Образец:** внешний отчёт «ЗадолженностьПоСрокамВозникновения» (форма `ФормаОтчета`, СКД + обычная форма), копия в `tests/fixtures/functional-report.erf` (+ XML-выгрузка `tests/fixtures/functional-report/`, тесты `tests/functional_report.rs`). **Изменение OpenSpec:** нет (закрытие долга V1/V2, часть V3).

Форма до правки: панель `ПанельНастроек` (id 29, 392,104; 300×386), `ShowTabs` = `0` (без закладок), одна страница «Страница1» (область 0,0,300,386).

## Команды (рабочий цикл на каждый вариант)

```
oneform pack w<N>                       # Form.xml правлен вручную/скриптом после extract; pack пишет Form.bin и перегенерирует Form.xml
epf-build  (копия каталога без src)  ->  w<N>.erf     # платформа собирает .erf из XML
epf-dump   w<N>.erf                  ->  w<N>_d       # платформа выгружает собранный .erf
oneform extract w<N>_d ; cmp  w<N>/…/Form.xml  w<N>_d/…/Form.xml     # повторный extract равен результату pack
python scripts/1c-e2e/live/live.py "ВнешнийОтчет.<путь>.erf" ФормаОтчета first out.txt shot.png "" [Панель.Страница]
```

Живой запуск теперь умеет внешний отчёт/обработку (`ВнешнийОтчет.<путь .erf>`) и текущую страницу панели до дампа; в дамп добавлены `ОтображениеЗакладок`, `Страницы.Количество()`, `ТекущаяСтраница.Имя` и др. (`launcher_module.bsl`, `live.py`).

## Дефекты, найденные проверкой

1. **`ShowTabs` 0 → 1 не пересчитывал область страниц** (w7, w8: в запросе 0,0,300,386, платформа выгрузила 1,19,298,366). Исправлено: `tabs_area_delta` (`src/form_patch.rs`); w9 и w16 совпали. Тесты: `show_tabs_of_an_existing_panel_moves_the_page_area`, `show_tabs_codes_other_than_none_and_top_are_refused_on_an_existing_panel`.
2. Новое поле, привязанное к простому реквизиту формы (`Примечание`), оставалось с типом донора (`ValueList`: кнопки списка и счётчика). Теперь тип берётся у самого реквизита (`form_attribute_type` в `binding_defaults.rs`); разбор `fixed` у реквизитов `String`. В выгрузке w14 расхождений с запросом по этому полю нет (в w10 было `<TextEdit>`).
3. Сообщение отказа `ShowTabs` код ≠ 0/1 содержало цепочку из ~30 пробелов — убрана.

## Не подтверждено

* Удаление, перестановка, `ShowTabs` 1 → 0 и повторное переименование (w2, w4, w16, w17, w18, w19) проверены платформой (сборка `.erf` и выгрузка), но **форма в живой 1С не открывалась**; в живой 1С открывались w6, w7, w10–w12, w14.
* Обработчик `Click` в дампе не виден (в дампе нет событий); форма с модулем открылась без ошибки, кнопку не нажимали.
* Не пробовали: сохранение отчёта в Конфигураторе, `ShowTabs` ≥ 2, перенос элементов между страницами, панель из нескольких страниц с закладками слева.
* `Видимость` элементов неактивной страницы в дампе остаётся «Да»; на какой странице элемент, видно только по снимку.
* V3 (форма отчёта из `new-form` против настоящей) этим прогоном не закрыта: здесь правилась готовая форма, шаблон `new-form --kind report` не сверялся.
