# property-sweep — сплошная проверка свойств (`e2e_sweep.py`)

**Дата:** 26.10.2026 (01:50–05:06). **База:** отдельная тестовая файловая база `target/db-real` (так задано в `scripts/1c-e2e/epf_dump.py`), внешняя обработка `tp-original.epf`, форма `ОсновнаяФорма` — **188 элементов и сама форма в дампе, 26 060 строк свойств**. Платформа 8.3.27.2342.

## Команды

```
python scripts/1c-e2e/e2e_sweep.py sweep1 [40] [1]  # до 40 мутаций на разных элементах (аргументы по умолчанию), extract + правка Form.xml + pack
python scripts/1c-e2e/epf_dump.py target/e2e-sweep1/tp.epf e2e-sweep1
python scripts/1c-e2e/dump_diff.py baseline.txt sweep1.txt post
```

Мутации: флажок true↔false, значение из частых значений того же тега, размер шрифта +1, цвет → `#123456` (по одному свойству на элемент). Список мутаций `mutations.json` в `target/` не сохранился.
