# fix-scany-form-pack-issues — проверка четырёх исправлений в живой 1С

**Дата:** 19.11.2026. **Платформа:** 1С:Предприятие 8.3.27.2342. **Базы:** «Управление торговлей» 10.3.52.2 (режим совместимости `Версия8_2_13`) и «Бухгалтерия» LogicCont 3.199 (`Версия8_3_9`). **oneform:** ветка `main` после коммитов `291f416`, `a8fbdac`, `6dbf205`, `3c250bc` (отладочная сборка). **Изменение OpenSpec:** `fix-scany-form-pack-issues`, задача 5.2.

## Как проверялось

Стенд проекта Scany1C (`processors/scany1c_v2_new/tools/stand`, скопирован в `C:\Temp`, репозиторий Scany1C не менялся): копия обработки `ОбработкаДляСайтаScany1C_v2_new.epf`, модуль главной формы заменён модулем стенда, стенд открывает форму по имени и пишет каждый элемент (тип, геометрия, у таблиц число колонок и строк) и результат экспортной функции формы.

В форме `ФормаФотоScany` модуль заменён минимальным ([test-form-module.bsl](files/fix-scany-form-pack-issues/test-form-module.bsl)): `ПриОткрытии` добавляет в `ТЗ1` колонки `Имя`, `Сумма` и одну строку и вызывает `СоздатьКолонки()`; `Проверка()` возвращает тип и кнопки поля без данных и число колонок таблиц. Две записи `oneform pack --experimental`:

1. В одном `pack`: элемент `ПолеФото` (`HTMLDocumentField`, `id 9`) заменён `LabelDecoration` `НадписьЗамена` с тем же `id` (pack напечатал предупреждение `control id 9 'ПолеФото' (HTMLDocumentField) is replaced by 'НадписьЗамена' (LabelDecoration): …`); добавлены 7 видов без подписи (`Chart`, `HTMLDocumentField`, `TextDocumentField`, `SpreadsheetDocumentField`, `GeographicalSchemaField`, `GraphicalSchemaField`, `PDFDocumentField`); реквизиты `ТЗ1`, `ТЗ2` (`ValueTable`); таблица `ТаблицаБезКолонок` (к `ТЗ1`, без `<Columns>`); таблица `ТаблицаБылиКолонки` (к `ТЗ2`, две колонки); поле `ПолеБезДанных` без `<DataPath>` и `<ValueType>`.
2. После `extract` у `ТаблицаБылиКолонки` удалён `<Columns>`, второй `pack`.

Итоговый `Form.xml`: [test-form.xml](files/fix-scany-form-pack-issues/test-form.xml). Запуск: `run.ps1 -Base ut|buh -Form ФормаФотоScany -Call "Проверка()"`.

## Результат

Обе базы: `rc=0`, форма открыта, вывод одинаковый ([УТ](files/fix-scany-form-pack-issues/report-ut.txt), [Бух.](files/fix-scany-form-pack-issues/report-buh.txt)).

| Исправление | Что показала 1С |
|---|---|
| Виды без блока свойств | все 7 элементов на форме своих типов («Диаграмма», «ПолеHTMLДокумента», «Поле текстового документа», «Поле табличного документа», «Поле географической схемы», «Поле графической схемы», «ПолеPDFДокумента») с запрошенной геометрией |
| Таблица значений без колонок | `ТаблицаБезКолонок`: `колонок=2 строк=1` — только колонки, созданные модулем; `ТаблицаБылиКолонки` после удаления колонок: `колонок=0` |
| Поле без данных | `тип=Строка список=Нет регулирование=Нет выбор=Нет` |
| Замена под прежним `id` | `НадписьЗамена` (Надпись) на месте `ПолеФото`; старого элемента нет |
| Новая командная панель с кнопками (PL-2) | форма с `ДействияФормы` (в `Form.xml` четыре кнопки-обработчика и разделитель) открыта; кнопки по отдельности стенд не выводит, см. [pilot-scany1c-command-bars-epf](pilot-scany1c-command-bars-epf.md) |

Строка «стенд не свернут: … (Свернутое)» относится к форме стенда, не к проверяемой форме.

## Не подтверждено

* Формы объектов конфигурации (`Ext/Form.bin`) и формы версий потока 25 / 26: проверялась только форма `.epf` версии 27.
* `<Caption>` у видов без блока свойств (отказ проверен тестами).
* Привязки (`Anchors`) новых элементов при растягивании окна: стенд менял размер, но размер формы не изменился (760×560 до и после), снимков нет.
* Нажатие кнопок и работа самих полей (ввод в поле без данных, отображение HTML/PDF).
