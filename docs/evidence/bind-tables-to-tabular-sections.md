# bind-tables-to-tabular-sections — таблицы и колонки табличных частей

**Дата:** 26.10.2026 (документы, обработка). **База:** «Бух.» (платформа 8.3.27.2342); внешняя обработка — через XML-выгрузку.
**Изменение OpenSpec:** `bind-tables-to-tabular-sections`, п. 1.1 и 1.7.

## Команды

```
oneform extract <выгрузка>; правка Form.xml (<Table> с <DataPath>Корень.Раздел</DataPath> и <Columns>; для обработки — mk_epf2.py ro|ed)
oneform pack <выгрузка>
scripts/1c-e2e/live/load.sh <cfg> <список> <лог>
python scripts/1c-e2e/live/live.py Документы.<Имя> ФормаДокумента new out.txt out.png
python scripts/1c-e2e/live/cmp.py …       # для обработки: python scripts/1c-e2e/epf_dump.py <epf> <метка>
```

Правленные `Form.xml` документов не сохранены, запрос читается только по результату.

## Не подтверждено артефактами

* Типы колонок (число, ссылка, перечисление), заявленные в `tasks.md`: в дампе колонок нет `ТипЗначения`; видны только редактор и привязка.
* «Равенство свойств свойствам существующих колонок того же вида»: дампов существующих колонок в этих прогонах нет, кроме [флажка](boolean-check-box-columns.md).
* Таблица с нулём колонок не пробовалась (сказано в `tasks.md`).
