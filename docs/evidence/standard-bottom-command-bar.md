# standard-bottom-command-bar — нижняя командная панель, как в Конфигураторе

**Дата:** 19.11.2026. **Платформа:** 1С:Предприятие 8.3.27.2342. **Базы:** «Управление торговлей» 10.3.52.2 (`Версия8_2_13`) и «Бухгалтерия» LogicCont 3.199 (`Версия8_3_9`). **oneform:** ветка `fix/bottom-command-bar` (отладочная сборка). **Изменение OpenSpec:** `standard-bottom-command-bar`.

## Как проверялось

Стенд проекта Scany1C (скопирован в `C:\Temp`, репозиторий Scany1C не менялся) открывает форму копии обработки и пишет элементы с геометрией. Окно снималось в интерактивном сеансе пользователя (задача планировщика с `/IT`, `PrintWindow`), сравнение кадров — попиксельно (`PIL.ImageChops`). Свойства, которых нет в `Form.xml`, читались модулем формы: `ЗначениеВСтрокуВнутр(ЭлементыФормы.<Панель>.Рамка)`, `Кнопка.КнопкаПоУмолчанию`.

| Вариант | Форма | Нижняя панель |
|---|---|---|
| A | `ФормаНастроек` старой обработки Scany (модуль заменён заглушками) | панель Конфигуратора `ОсновныеДействияФормы` (id 3) |
| B | то же | XML панели A удалён и добавлен заново `pack` 0.4.1 (id 33) |
| B4 | то же | B, в потоке вручную: заголовок формы `root[1][1][2]=33`, рамка `7`, `info[1][11]=31` |
| V1 | то же | панель из минимального запроса (без `HorizontalAlign` / `AutoFill` / `Anchors` / `Secondary` / `representation`, `DefaultButton` у «Выполнить»), `pack` этой ветки |
| C | `ФормаНастроек` текущей обработки Scany | панель Scany `ДействияНастроек`: `Left 116`, `Width 480`, привязки к правому краю, без `HorizontalAlign` и разделителей |
| V2s | то же | панель C удалена и добавлена заново с той же геометрией, `pack` этой ветки |
| V2 | то же | панель по тексту предупреждения `pack`: `Left 0`, `Top 485`, `Width 600`, `Height 25`, разделители, `DefaultButton` у «OK» |

## Результат

| Вариант | Что показала 1С |
|---|---|
| B | без линии над панелью, «Выполнить» не жирная, `КнопкаПоУмолчанию=Нет` |
| B4 | попиксельно равна A по всей форме; `КнопкаПоУмолчанию=Да` |
| V1 с `Secondary=1` (первая сборка) | заголовок и `[11]` верны, но `КнопкаПоУмолчанию=Нет`; с `[1][5]=0` — `Да` (вспомогательная панель кнопку по умолчанию не держит) |
| V1 с `representation` по умолчанию `Auto` | «Закрыть» (`Standard:142`) нарисована значком ✕ |
| V1 (итог) | всё окно 1С попиксельно равно A в обеих базах; `КнопкаПоУмолчанию=Да`; окно 800×560 — панель `0,535,800,25` |
| V2s | кнопки справа, линия над панелью; геометрия Scany сохранена, `pack` напечатал `warning ... Left 116 -> 0, Width 480 -> 600, Top 479 -> 485, anchors -> ...` |
| V2 | панель на всю ширину, линия сверху, разделители, «OK» жирная, в обеих базах; окно 800×600 — панель `0,575,800,25` |

Коды `ТипРамки` (`Новый Рамка(ТипРамкиЭлементаУправления.X, 1)`): 0 `БезРамки`, 1 `Одинарная`, 2 `Выпуклая`, 3 `Вдавленная`, 4 `Подчеркивание`, 5 `ДвойноеПодчеркивание`, 6 `Скругленная`, 7 `ЧертаСверху`, 200 `Двойная`.

Корпус УТ (`target/corpus/ut2`, 1525 форм): заголовок формы указывает на панель в 782 формах, у всех них `info[1][11]` не 0; у остальных 2099 панелей `[11]=0` в 2092. Рамка 7 — у 590 из 782 таких панелей; `Secondary=0` — у 781 из 782 (у прочих панелей `Secondary=1` почти всегда). `representation` кнопок нижних панелей: `Auto` 601, `Text` 461, `PictureAndText` 351.

## Не подтверждено

* Формы объектов конфигурации (`Ext/Form.bin`) и формы версий потока 25 / 26 (добавление `CommandBar` там отклоняется и раньше).
* Смысл `b[13]` записи кнопки, `[6]` записи действия и `[0]` хвоста группы: у A и B они разные, но B4 с прежними значениями равна A.
* Нижняя панель на странице `Panel` (по правилу не считается нижней).
* Перенос кнопки по умолчанию на `Button` и обратно — только тестами (у `Button` флаг делит слот с `MenuMode`, проверка упакованной формы на этот случай не рассчитана).
