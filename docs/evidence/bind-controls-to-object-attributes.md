# bind-controls-to-object-attributes — привязка полей к реквизитам объекта (A1)

**Дата:** 26.10.2026 (справочник и документ), 26–27.10.2026 (поздние прогоны). **База:** «Бух.» (файловая, платформа 8.3.27.2342, обычное приложение, пользователь `admin`), внешняя обработка — через XML-выгрузку.
**Изменение OpenSpec:** `bind-controls-to-object-attributes`, п. 1.7.

## Команды

```
oneform extract <выгрузка конфигурации>            # src/Forms/<Форма>/Form.xml
python scripts/1c-e2e/live/edit_cat.py <Form.xml>   # 4 поля: СправочникОбъект.Код / .Наименование / .ЗапретРедактирования / .Счет2020
oneform pack <выгрузка конфигурации>
scripts/1c-e2e/live/load.sh <cfg> <список> <лог>   # частичная загрузка, UpdateDBCfg
python scripts/1c-e2e/live/live.py Справочники.<Имя> ФормаЭлемента first out.txt out.png
python scripts/1c-e2e/live/cmp.py до.txt после.txt <новые элементы> pre
```

Правленный `Form.xml` в артефактах не сохранён (только `edit_cat.py` для справочника); «запрошено» сверяется по `tasks.md` и описанию в `todo.md`.
