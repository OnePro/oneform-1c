## Что не подтверждено или найдено попутно
* Предупреждение о типе по умолчанию (`ValueList`) не воспроизведено: без метаданных объекта `pack` отказывает (`data-path: object metadata not available…`) — это честный отказ, но само предупреждение живьём не проверено.
* **Находки без исправления:** (1) уменьшение главной панели через `pack` принимается молча, `lint` потом даёт `outside-container`; (2) правка только модуля, которая добавляет ссылку на уже отсутствующий элемент, предупреждения не вызывает (предупреждения привязаны к удалению/переименованию в этом же `pack`).
* Нажатие кнопок нового панели не проверялось (только связь действия с процедурой).
* Платформенные модальные окна 1С при открытии учитывались вручную по скриншоту.
