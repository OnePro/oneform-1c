# add-panel-with-pages — панель со страницами

**Дата:** 27.10.2026 (06:45 и 08:34). **База:** «Бух.» (платформа 8.3.27.2342), справочник «Доходы будущих периодов». **Изменение OpenSpec:** `add-panel-with-pages`, п. 1.3.

**Проверен только этап A (новая панель). Этап B (страницы существующей панели: переименование, добавление, удаление, перестановка) в живой 1С НЕ проверялся — артефактов нет (долг V1); `ShowTabs` у существующей панели — тоже нет (V2).**

## Команды

```
oneform extract <выгрузка>; в Form.xml формы ФормаПанели добавлен <Panel> с <Page> «Основное» и «Списание» и элементами страниц; oneform pack
scripts/1c-e2e/live/load.sh <cfg> list-pn.txt out/load-pn
python scripts/1c-e2e/live/live.py Справочники.ДоходыБудущихПериодов ФормаПанели first out/pn.txt out/pn.png
```

Второй прогон (08:33): та же загрузка + форма `ФормаАгентаН` (подписи, поля `Код`, `Наименование`, панель) — `live.py Справочники.ДоходыБудущихПериодов ФормаАгентаН first out/h.txt out/h.png`.

## Не подтверждено

* Панель на обработке/отчёте и корневая панель формы; `ShowTabs` ≥ 2; перенос элементов между страницами.
* Привязки (Anchors) при растягивании окна: снимки до/после изменения размера не снимались (V9).
* Правленный `Form.xml` не сохранён: «чистая панель без содержимого донорской» видна только как состав страниц.
