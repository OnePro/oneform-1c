# lossless-datapath-steps — связи без потерь (S1)

**Дата:** 26.10.2026. **База:** «Бух.» (платформа 8.3.27.2342). **Изменение OpenSpec:** `lossless-datapath-steps`, п. 1.4.

## Команды

```
oneform extract <выгрузка>; pack без значимых правок формы «Операция»   # форма с таблицей проводок, связь Движения.<регистр>
scripts/1c-e2e/live/load.sh <cfg> <список> <лог>
python scripts/1c-e2e/live/live.py Документы.Операция ФормаДокумента new out.txt     # до и после загрузки
```

Список загрузки: `Documents/Операция.xml`, `Forms/ФормаДокумента.xml`, `Forms/ФормаДокумента/Ext/Form.bin`.

## Результат

* Дампы [до](files/lossless-datapath-steps/document-operation-before.txt.gz) и [после](files/lossless-datapath-steps/document-operation-after.txt.gz) совпадают **побайтно** (по 283 883 байта, 2 859 строк); `ТаблицаПроводок.Данные = Движения.ПланСчетовОсновной` в обоих; `ФОРМА.Ширина = 700`, `Высота = 429` в обоих.
* Между снятиями форма была перепакована: `Form.bin` в рабочей выгрузке (81 897 байт) отличается от исходного (81 928 байт).
* Побайтное равенство 15 518 связей корпусов УТ и Бух. — офлайн (тесты и прогон по корпусам, не живая 1С).

## Не подтверждено артефактами

* Что именно было изменено в форме (формулировка «правка ширины формы» в `todo.md`): сохранённого правленного `Form.xml` нет, а `ФОРМА.Ширина` в обоих дампах равна 700. Доказано только: после перепаковки и загрузки все свойства всех элементов формы, включая многошаговую связь `Движения`, не изменились.
