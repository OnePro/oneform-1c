## 4. Пробелы относительно цели (по частоте × вреду)

Корпус: 2945 форм, из них обработки 650 и отчёты 537 (≈40 %) (`form-design-standards.md`). Панели: в УТ в 376 формах из 1464, в Бух. — в 407 из 1481. `ShowTabs = 0` у 431 из 705 и 409 из 736 панелей; панелей из одной страницы 210 и 370 (`panel-pages-advisor-report.md:76-82`).

1. **Бинарный `.erf` не читается `extract`** — касается всех внешних отчётов (приоритет №1), без `erf-dump` работа не начинается. Вред высокий, размер S: возможно, хватит добавить `.erf` в `discovery.rs`, но это надо проверить.
2. **Нельзя включить закладки у существующей панели, нельзя переносить элементы между страницами** — касается ~57 % панелей (без закладок) и ~38 % (одна страница). Перекройка раскладки — частая задача, отчёт 3 задача I застряла именно здесь. Вред высокий.
3. **Шаблон отчёта = шаблон обработки** — касается каждой новой формы отчёта. Код агента с `ОтчетОбъект` не заработает. Вред средний и высокий.
4. **Размер формы не перенастраивает командные панели и привязки** — касается каждой новой формы (отчёт 1 п. 5, отчёт 2 п. 2, ошибка ФормаАгентаБ). Сейчас это закрывают `lint` и навык; автоисправления нет. Вред средний.
5. **Новый элемент обязан стоять в конце `ChildItems` (B7)**, а сообщение об отказе вводит в заблуждение (`form_patch.rs:4946`). Вредит при каждой правке; размер S.
6. **Колонки таблицы значений: ссылки, составные типы; B1 (колонка «только чтение» → редактируемая)** — касается обработок с табличными полями. Вред средний.
7. **Свойства новых кнопок (картинка, сочетание клавиш); картинки не показаны в XML (B9)** — частые в командных панелях. Вред низкий и средний.
8. **Для справочников и документов:** `Корень.Имя.Поле`, `Проведен` / `ПометкаУдаления`, форма по метаданным (иерархия, проведение) — второй приоритет.
9. **Редкое:** дубли имён (в 25 формах корпусов `lint` даёт `error`, ≈0,8 %), формы 8.0 (≈4 % УТ), ActiveX (0 % по `roadmap-to-90-percent.md:27`).

**Калибровка `lint` на корпусах (прогнал сам):**
- УТ: ошибки в 18 формах из 1464 (33 `duplicate-name`, 30 `outside-container`);
- Бух.: в 7 формах из 1481;
- то есть `error` срабатывает примерно на 0,8 % типовых форм — для правила уровня error это приемлемо.
