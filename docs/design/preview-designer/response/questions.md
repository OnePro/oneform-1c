## Неясности

1. **Кнопка выбора у поля без `ChoiceButton`.** В 02 у полей ссылочного типа кнопка «…» есть без тега, а у строковых — нет. Тип поля в Form.xml виден не всегда (только через `DataPath` на реквизит). Правило в §3: кнопка рисуется, если тег есть и `true`, либо тег отсутствует и тип ссылочный/дата/число. Если тип определить нельзя, кнопку не рисуем. Подтвердите, что так правильно.
2. **Горизонтальная полоса прокрутки таблицы при `AutoUse`.** На снимках 01 и 06 она видна, даже когда колонки помещаются. Мы рисуем её всегда, а вертикальную — только когда строки не помещаются. Это поведение платформы или особенность этих форм?
3. **Цвета `kind="style"` без `value`** (например, `style:ТекстЗапрещенногоЭлементаФормы`) считаем отсутствующими (§0.6). Если для стилей есть таблица значений (стиль конфигурации), пришлите её — заменим на конкретные цвета.
4. **Картинки по ссылке (`refGuid`)**: пикселей в Form.xml нет, поэтому рисуем заглушку `icon-picture` 16×16 или пустую рамку `.pic-box`. Есть ли доступ к общим картинкам конфигурации, чтобы подставлять настоящие?
5. **Отметка незаполненного (`AutoMarkIncomplete`)** показана только в designer у пустого поля. В runtime-образце значения заполнены, поэтому отметки нет. Это ожидаемо?
6. **Язык подписи ro**: если румынской подписи нет, выводим пусто (у надписи — `<<Имя>>`). Нужна ли подстановка русской подписи как запасной?
7. **Темы `xp` и `v82`**: все снимки — 8.2/8.3, поэтому палитра снята только для `v82`. Переменные `xp` в `form_theme.css` не трогали — можно ли считать `xp` устаревшей?

## Предложения

1. Применить список изменений `form_render.js` из §26 `render-spec.md`, без них часть правил (`.ro`, `.dis`, значки полей, шрифты, цвета `kind=style`, автозаполнение командных панелей) не сработает; CSS для всех этих классов уже в `theme.css`.
2. Подключать `theme.css` после `form_theme.css` как отдельный слой (`--overlay`), а после внедрения — слить в `form_theme.css` и удалить дублирующиеся правила.
3. Набор значков `ICON.*` заменить на значки §0.5 (inline SVG, имена совпадают по смыслу).
4. Добавить в `build_samples.py` образец с недоступными элементами и с группой `Frame`, чтобы после получения эталонов сравнить попиксельно.
5. Закладки панели не ужимать (как в 1С): лишние уходят за край, справа стрелки `.pscroll` — это уже в `theme.css`, но нужна правка `tabsHtml()` (убрать `max-width:92px`).
