# 02. Каталог свойств (справочник дизайнера)

Это **справочник**: его читают, в нём ничего не заполняют. Результат вашей работы — макет `style-sheet.html` и инструкции `render-spec.md` (см. `05-what-to-return.md`); в них каждое свойство из этого каталога по ID получает вид и правило для HTML/CSS. Файл создан скриптом `scripts/gen_designer_catalog.py` (данные строк — `scripts/designer_catalog_data.py`); руками не правится.

## Как читать

* **ID** — устойчивое имя вида `Класс.Тег` (для атрибутов `Класс.атрибут`, для общих структур `Font.bold`). На него ссылайтесь в `data-xml="…"` листа образцов и в правилах `render-spec.md`.
* **XML** — как свойство выглядит в настоящем `Form.xml` (взято из реального файла корпуса; `⚠` — в корпусе не встречается, пример по `docs/xml-reference.md`). В Form.xml записываются только значения, отличающиеся от «нового элемента»; отсутствие тега = значение по умолчанию.
* **Конфигуратор** — название свойства в окне «Свойства» (русское имя из справочника платформы).
* **Как выглядит в 1С** — что известно о настоящем виде: ссылка на картинку из `gallery/` или `нет эталона` + выдержка из справки платформы.
* **Что делает превью сейчас** — **рисуется** / **частично** / **игнорируется** / **только inspector** (значение видно только в боковой панели, на холсте нет) и имя функции в `assets/form_render.js` (номер строки — в текущей версии файла из `tools/assets/`).
* **Частота** — `N / T`: в скольких формах корпуса свойство задано **не по умолчанию** (для тегов без известного умолчания — просто присутствует) из T форм; `эл.` — число элементов; затем самые частые значения.
* Внутри класса строки отсортированы: сначала то, что превью **игнорирует**, и чаще встречающееся; затем частично рисуемое; затем рисуемое.

Учтено **2983** обычных форм (уникальных по содержимому); пропущено: 29 управляемых форм, 7 дублей, 0 не разобрано. Источники (Form.xml в формате нашего инструмента, `ordinaryFormVersion`):

* Бух. — 1491 форм
* УТ — 1464 форм
* УТ 10.3 — 18 форм

Это выгрузки конфигураций «Управление торговлей» и «Бух.», где обычные формы хранятся в том же `Form.xml`, что и в нашем инструменте. Время сканирования: 34.1 с.
