## Решения владельца (28.10.2026)

1. **Вне плана навсегда:** `ActiveXControl`, формы формата 8.0, формы с дублями имён элементов (нестандартные формы; операционное определение — `oneform validate` даёт `OUT_OF_SCOPE`, см. `agent-guide.md`, «Область применимости»). Правка таких форм — в Конфигураторе.
2. **Полный компилятор формы «с нуля» (на Rust или Python) не строится.** Продукт — патчер + донорские прототипы + шаблоны. Экспериментальный Python-компилятор остаётся только справочником формата и не развивается.
3. **`preview` — приблизительная раскладка** (положения, размеры, привязки). Точная до пикселя отрисовка отложена до окончательного вида XML.
4. **Фокус:** сначала обработки и отчёты, потом формы справочников и документов.

## Правила процесса

1. Изменение OpenSpec с пунктом «Checked in 1C» не архивируется без `evidence.md`: команда, база, путь к дампу, диффу или снимку в git.
2. Строки «Проверено» в `agent-readiness.md` и таблицы тегов (`xml-reference.md`) по возможности генерируются тестами или скриптами.
3. `todo.md` — единственный бэклог; крупные задачи оформляются изменением OpenSpec (`propose → validate → apply → test → archive`).
4. Эталоны `GOLDEN_BLESS` принимаются только с диффом в коммите.
5. Статус 🟢 в `compatibility-matrix.md` и `rw` в `property-coverage-map.md` означают «поток читает и пишет по каталогу и тестам», а не «проверено в живой 1С».

## B. Ограничения редактирования

Форма **в области применимости** (`IN_SCOPE`) тогда и только тогда, когда она обычная формата 8.2/8.3, в ней нет неподдерживаемых видов элементов (`ActiveXControl` и т. п.), имена элементов уникальны, она без правок проходит путь «поток → `Form.xml` → поток» байт в байт, а её проекция `src/` актуальна. Иначе — `OUT_OF_SCOPE`: правьте такую форму в Конфигураторе. Команда `oneform validate` (изменение `add-form-scope-validator`) выдаёт этот признак по каждой форме, коды причин — в `agent-guide.md`; доли по корпусам — в `agent-readiness.md`, «Область применимости».

## E. Что решено не делать

- Полный компилятор формы «XML + донор → поток» на Rust или Python и полная расшифровка всех бинарных записей: дорого, для правки существующих форм не нужны (решение владельца 28.10.2026).
- Пиксельно точный HTML-предпросмотр: есть приблизительный; точную картинку даёт только 1С; вернуться, когда XML станет окончательным.
- `ActiveXControl`, формы формата 8.0, формы с дублями имён — навсегда (B2, B4, B5).
