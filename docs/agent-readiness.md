# Готовность oneform для ИИ-агентов: что проверено и что нет

Состояние на 26.10.2026. Руководство для агента: [`agent-guide.md`](agent-guide.md).

## Проверено

| Что | Как | Результат |
|---|---|---|
| `extract` → `pack` без правок | 687 объектов, 1464 формы УТ 10.3 | ничего не меняется; повторный `extract` идемпотентен |
| Свойства: по одному на объект | `scripts/fuzz_corpus.py`, 672 мутации | 562 упаковано, у всех изменена только мутированная строка; остальные — понятные отказы |
| Структура: добавить/удалить/переименовать/сдвинуть/подпись | `scripts/fuzz_struct.py`, ~640 мутаций | добавление 121/121, удаление 132/136, переименование 141/144, сдвиг 149/152; повторный `pack` ничего не меняет |
| Граф привязок (`Anchors`) | `anchor_graph_violations`, тест `tests/anchor_graph.rs` | 0 нарушений на всех 1525 формах корпуса и на результатах фаззинга |
| Живая 1С, обработка с 188 элементами | `scripts/1c-e2e` | правки свойств + добавление + удаление через `oneform`: в дампе свойств всех элементов только ожидаемые отличия |
| Живая 1С, пакет из 40 разных свойств на 40 элементах | `e2e_sweep.py` | отличий на несмотренных элементах нет, форма открывается |
| Живая 1С, добавление элемента в 3 малые формы | `e2e_small.sh` | 0 отличий у существующих элементов |

## Что выяснено по дороге

* Новый элемент без согласованных обратных ссылок привязок ломал раскладку всей формы в 1С (форма не растягивалась) —
  это не видно ни в тестах, ни в XML; исправлено, см. `src/form_patch/anchors.rs`.
* Размер шрифта: правка размера сбрасывала курсив/подчёркивание/зачёркивание; исправлено.
* Служебные бинарные записи занимали 70 % `Form.xml`; теперь по умолчанию их нет.

## Известные ограничения

* Формы формата платформы 8.0 (≈4 % УТ 10.3): доступен только модуль.
* Формы с дублирующимися именами элементов (≈0,6 %): правка XML отклоняется.
* Заголовки кнопок командных панелей со стандартными действиями и панелей с вложенными подменю (≈15 % таких правок): не поддержано.
* Смена `ReadOnly` табличного поля с колонками «только чтение»: отклоняется.
* Удаление элемента, на который привязаны другие: зависимые сохраняют положение, но растягиваются иначе.
* Конфигурационные формы (`Ext/Form.bin`) проверены тестами и фаззингом, но не в живой 1С: тестовая база даёт на открытии
  исходной формы собственную ошибку (отсутствуют реквизиты конфигурации).

## Следующее

1. Создание форм «с нуля»: пустая обработка/форма-шаблон и регистрация формы в объекте (EPF — быстро, конфигурация — дольше).
2. Проверка конфигурационной формы в живой 1С на полной конфигурации.
3. Заголовки/состав кнопок командных панелей (стандартные действия, подменю).
4. Постепенная расшифровка бинарных записей в читаемые свойства (шрифты/цвета заголовков таблиц, форматы колонок, картинки).
