# Стандарты дизайна обычных форм

Правила выведены из двух реальных конфигураций: **УТ 10.3 и Бух.** (формы обычного приложения). Числа посчитаны скриптами `scripts/design/analyze_forms.py` и `scripts/design/render_standards.py`; машинная версия — `docs/design/design-rules.json` (id правила, вид формы, параметр, значение, доля, n). Файл генерируется, руками не правится.

Как читать: ячейка «`8 (96 %, n=162)`» — модальное значение, доля наблюдений с ним, число наблюдений n (форм или элементов — по смыслу строки; доли считаются только по формам/элементам, где объект есть). «да (…)» — доля `да`. «`p10/p50/p90`» — квантили. Порог «стиль един» — 80 %; всё, что ниже, вынесено в раздел «Где стили расходятся». Единицы — пиксели обычной формы.

Формы: всего 2945 (заготовки без полей/таблиц/панелей не участвуют в геометрии).

## Где стили расходятся

## Что не измерено

- Шрифт заголовков таблицы, шрифт колонок и цвета строк из бинарной записи `Appearance` не разбираются; в XML есть только явные `HeaderFont`/`Font`/`TextColor`/`BackColor` — их доли даны, остальное неизвестно.
- Реальные размеры шрифта и ширина текста в пикселях: нет данных, соотношение «длина подписи → ширина подписи» не выведено.
- Взаимное положение контролов внутри группы (`UsualGroup`) — в корпусах группа это рамка-заголовок без дочерних элементов, вложенной геометрии нет.
- Отношение «рамка — её содержимое» (элементы внутри рамки `UsualGroup` по геометрии) отдельным правилом не оформлено.
- Связь жирной подписи с обязательностью: `FillChecking=ShowError` в XML объектов у реквизитов, вынесенных на формы, редок (у документов n=12), поэтому вывод по нему статистически слаб.
- Модульные имена обработчиков, подсказки (`Tooltip`), события, мобильные формы, управляемые формы (корпусы — только обычные формы).
- Колонка «все» в JSON объединяет два корпуса пропорционально числу наблюдений; УТ даёт больше форм документов, Бух. — отчётов и обработок.
- Автоматически созданные заготовки (форма обработки с панелью, одной надписью и нижней панелью — 144 формы Бух., 4 формы УТ) исключены из геометрии (`form.stub`).
